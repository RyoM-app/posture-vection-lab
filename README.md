# 姿勢・ベクションラボ 0.2.0

スマートフォンの前面カメラとIMUから頭部傾きの変化を記録し、オプティックフローを提示する研究用試作です。既存のposture-lab 0.1.1とvection-demoの描画を統合しました。

## 操作
1. HTTPSで開き、カメラと動作・方向の権限を許可します。
2. 縦持ちで基準姿勢を3秒記録します。距離の1点校正は任意です。
3. モード、継続時間n、角度m、刺激パターン・向き・速度割合を設定します。
4. 「文章・課題画面へ進む」で記録が始まります。画面右側の縦スロットルで自己運動感の強さだけを0〜100で報告します。上が100、下が0です。スロットルは刺激速度を操作しません。
5. 終了後、保存する記録を選び、刺激ごとに自己運動感の前後方向・体勢変化の自覚・補足を回答します。「覚えていない」も選べます。回答は端末内に退避されます。計測CSV、刺激・回答CSV、全記録JSONを保存してください。回答後の再出力が必要です。方向の回答は後からの振り返りであり、提示中の方向時系列ではありません。
6. 刺激強度・速度・n・m・提示時間などは設定画面のスライダーで調整します。現在値を併記します。

## モード
- 姿勢連動：有効な頭部角度が基準＋m度をn秒連続で超えると刺激提示し、基準＋m度以内に戻るまで継続します（初期値m=10度）。固定の提示時間は適用しません。両方向を選ぶと絶対値がm度以内、上向きを選ぶと−m度以上で復帰です。復帰後は指定休止時間を置いて、改めてn秒の逸脱を判定します。
- ランダム比較：選んだ1パターンについて両方向×設定強度の1/3・2/3・全量と静止対照の7条件を反復ごとにシャッフル。乱数seed・順序をJSONに保存。各条件は3秒準備、指定時間提示、指定時間休止。欠測で中断した試行は失敗理由を残し、次の試行に進みます。パターン比較は別セッションで行ってください。
- 静止対照でも同じドット場を表示します。強度は仮想空間の速度割合であり知覚強度ではありません。回転パターン＋は正面の粒が上向きに流れ、放射状＋は拡大します。知覚・身体反応の方向は未検証です。

## 記録と品質
- 顔の回転行列、虹彩径・奥行き、IMUの全イベント、各フレームの刺激状態・スライダー値、課題回答、刺激開始終了、描画時刻を記録します。
- 記録時刻は同じperformance.timeOriginを使います。画像の露光時刻・ディスプレイの実発光時刻とのハードウェア同期はありません。
- 既定の刺激判定範囲はカメラ基準pitch -20〜+10度です。これは1名の予備記録からの探索的設定で、精度保証ではありません。設定で変更できます。元の顔品質条件（pitch±40、yaw/roll±25、IMU受信250ms以内）も適用します。
- 頭部角度が無効、設定範囲外、画像更新500ms超なら刺激を止め、連続逸脱時間をリセットします。姿勢連動で提示中の場合は同じ試行を一時停止し、有効値の復帰後、まだ逸脱していれば再開、範囲内なら終了します。pause/resumeと休止時間を記録します。ランダム比較ではその試行を中断として扱います。画面非表示、カメラ停止、画面回転、20分上限では実験終了。
- IndexedDBの専用DBに約5秒ごとに退避します。ダウンロード完了はOSのファイル画面で確認してください。画像・音声は保存・送信しません。
- 実験後の回答はJSONのmeta.experiment.postResponsesと、イベントのpost_experiment_responseに保存されます。刺激・回答CSVにもイベントとして含まれます。計測CSVのsensationは0.2.0から符号なしの強さ0〜100です。旧版の±100とは尺度が異なります。
- JSONが完全な記録です。CSVの角度は解剖学的CVAではありません。手持ち時の顔・端末間距離から頭部前方偏位は特定できません。

## 使用環境と確認範囲
HTML/CSS/JavaScriptのみ。GitHub PagesなどHTTPS静的配信で利用します。MediaPipe tasks-vision 1.0.1とface_landmarker/float16/1をネットワークから取得します。iPhone・Androidでの統合版のカメラ動作、提示性能、スライダー操作中の姿勢への影響は実機で確認が必要です。実装の自動テスト・スマートフォン実機試験は今回実施していません。

MediaPipe: https://github.com/google-ai-edge/mediapipe (Apache-2.0)。刺激描画は提供されたvection-demoを継承。第三者に対する試験では所属先の研究手続きに従ってください。着座で使用し、違和感があれば画面の「中止」で終了できます。
